# 从一个能用的博客开始

做这个博客，不是为了先设计一套很复杂的系统。

更重要的是先有一个可以稳定写作、方便维护、能够长期积累的地方。

## 先解决写作问题

内容使用 Markdown 保存，代码和文章都可以放在 Git 仓库里。这样做的好处是简单、透明，也方便以后迁移。

## 风格保持克制

页面只保留真正有用的结构：

- 左侧是文章目录
- 中间是正文
- 右侧是当前文章的小目录
- 顶部只保留 GitHub 链接

其余功能等有真实需求之后再加。

## 后面再慢慢整理

博客的栏目不会一开始就设计得过细。先持续写，等内容形成规模，再根据实际文章调整目录结构。
